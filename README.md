# Tic Tac Toe

A classic Tic Tac Toe game built with HTML, CSS, and JavaScript, featuring three difficulty levels:
- **Standard (2 Players)**
- **Easy AI (Random Moves)**
- **Hard AI (Minimax Algorithm)**

---

## Link https://leoandradej.github.io/tic-tac-toe/

---

## Features

- 2-player mode
- Easy AI (random moves)
- Hard AI using the **Minimax algorithm**\
- Restart and reset functionality
- Responsive layout and smooth UI
